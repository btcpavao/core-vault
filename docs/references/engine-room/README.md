# Engine Room — Approved Visual Reference

`engine-room-hero-reference.png` is the approved Hero Reference Image for the Core Vault Engine Room.

It defines the intended:

- architecture
- composition
- spatial proportions
- material language
- Reactor scale and placement
- lighting
- atmosphere
- depth
- visual hierarchy
- overall realism and production quality

The final real-time Engine Room does not need to reproduce every microscopic detail or individual object exactly.

However, the goal is **near-reference fidelity**.

A screenshot of the final Engine Room from its designated `CV_HeroCamera` should be immediately recognizable as the same environment represented by this reference image.

The reference must therefore be treated as an **acceptance target**, not merely as artistic inspiration.

The production process for reconstructing this environment is defined in:

```text
docs/ART_PRODUCTION_PIPELINE.md
```

The Engine Room should be the first Core Vault environment to pass the complete pipeline before the same process is scaled to other rooms.
