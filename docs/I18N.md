# Internationalization

Core Vault currently ships in English only. `src/i18n.ts` retains a small translation-key boundary so additional languages can be added without scattering copy through spatial-shell components.

- The document language is always `en`.
- Settings no longer presents a language selector.
- Old stored language preferences fall back to English.
- Backend errors, the spatial shell, the preserved 2-of-3 workshop, tests, and repository documentation all use English.

Before adding another language, extract any remaining inline operational strings and add tests for interpolation, pluralization, long-label layout, and screen-reader announcements. A language option should appear only when its full user-visible flow is translated and tested.
