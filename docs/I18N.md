# Internationalization

The spatial shell ships English and Croatian copy in `src/i18n.ts`.

- Croatian is selected when the operating-system locale begins with `hr`; otherwise English is the fallback.
- The user can change language in Settings. Only this non-sensitive preference is stored locally.
- Network identifiers, RPC names, addresses, transaction IDs, and exact legal/attribution text are not translated.
- The preserved 2-of-3 legacy workshop remains English-first in this prototype.

Before expanding language coverage, extract remaining inline operational strings and add tests for interpolation, pluralization, long-label layout, and screen-reader announcements.
