# First-run walkthrough

The walkthrough has three short concepts:

1. Rooms organize wallet tasks without gamification.
2. Local Bitcoin Core remains the source of truth.
3. Receiving and spending include explicit verification steps.

It can be skipped immediately or replayed from Settings. Sound consent follows as a distinct optional step. Completion and sound choice are non-sensitive interface preferences stored under `core-vault:preferences:v1`.

The walkthrough never claims that Core Vault replaces Bitcoin Core, guarantees security, creates an air gap, or is ready for real funds.
